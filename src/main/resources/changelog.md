## 1.3.0
- Added "Lists" section to the side panel where you can customize your own upgrade lists
- Added importing/exporting lists
- Added colors to item requirements indicating if you have the materials or not
- Added "View in bank" button to all upgrade cards to auto-filter your bank for the required materials
- Added right-click option "Import tag tab Boat Upgrades" to the "New tag tab" button in the top left of the bank. This will automatically import a bank tag layout containing every sailing material

## 1.2.0
- Added side panel for displaying available upgrades
- Upgrade names and materials in the side panel can be clicked and will link to their wiki page
- Added setting for specifying position of the side panel
- Added setting for showing text overlay only when in the shipyard
